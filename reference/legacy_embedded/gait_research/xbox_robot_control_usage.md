# Xbox 手柄控制程序使用文档

## 1. 程序位置

手柄控制程序：

```powershell
E:\Fudan\worms\codes\xbox_robot_control.py
```

运行命令：

```powershell
python E:\Fudan\worms\codes\xbox_robot_control.py
```

该程序是独立控制程序，不需要打开 `robot_v2_no_imu.py`。

---

## 2. 使用前准备

### 2.1 硬件

需要确保：

- 五个体节的 `ESP32` 已上电
- 五个体节的 `STM32` 已上电
- 舵机电源已上电
- 上位机电脑和 `ESP32` 在同一网络内
- `ESP32` 固件中的 `serverIP` 指向当前上位机电脑 IP
- Xbox 手柄已经连接到电脑

### 2.2 固件

当前手柄控制脚本依赖以下运动模式：

| 功能 | 协议模式 |
| --- | --- |
| 蠕虫步态 | `0x01` |
| 蛇形直线 | `0x02` |
| 蛇形左转 | `0x04` |
| 蛇形右转 | `0x05` |

如果要使用蛇形左转和右转，需要烧录支持 `0x04/0x05` 的最新版 `STM32` 程序。

`ESP32` 不需要因为新增 `0x05` 单独修改，因为它只负责透传 6 字节命令。

---

## 3. 启动流程

1. 给五个体节和舵机上电。
2. 确认 Xbox 手柄已经连接。
3. 打开 PowerShell。
4. 运行：

```powershell
python E:\Fudan\worms\codes\xbox_robot_control.py
```

启动后会出现一个小窗口，显示：

- 当前电脑 IP
- 手柄连接状态
- 已连接的体节编号
- 每个体节的连接状态
- 最近一次发送的命令
- 最近一次发送结果

## 4. 按键映射

当前使用 8 个按键：

| 手柄按键 | 功能 | 协议命令 |
| --- | --- | --- |
| `A` | 蛇形直线 | `0x02`, 振幅 `45°` |
| `X` | 蛇形左转 | `0x04`, 振幅 `45°` |
| `B` | 蛇形右转 | `0x05`, 振幅 `45°` |
| `Y` | 全部归位 / 停止 | `0x01`, 步态 `8` |
| 十字键上 | 蠕虫步态 1 | `0x01`, 步态 `1` |
| 十字键右 | 蠕虫步态 2 | `0x01`, 步态 `2` |
| 十字键下 | 蠕虫步态 3 | `0x01`, 步态 `3` |
| 十字键左 | 蠕虫步态 4 | `0x01`, 步态 `4` |

说明：

- 蛇形振幅固定为 `45°`
- 当前没有使用左右摇杆
- 当前没有使用肩键和扳机键
- 程序只响应“按下瞬间”，长按不会连续重复发送

## 5. 状态窗口怎么看

### 5.1 手柄状态

窗口中如果显示：

```text
controller: connected on slot 0
```

说明手柄已经被 `XInput` 正常识别。

如果显示：

```text
controller: disconnected
```

说明系统当前没有检测到可用的 Xbox/XInput 手柄。

### 5.2 体节连接状态

窗口会显示：

```text
connected segments: [0, 1, 2, 3, 4]
```

这表示五个体节都已经连接。

如果只看到部分编号，例如：

```text
connected segments: [0, 2, 4]
```

说明只有 0、2、4 号体节连上了上位机，其余体节没有连接成功。

### 5.3 最近命令

窗口会显示最近一次发送的命令，例如：

```text
last action: snake_forward_45
last result: 5/5
```

含义：

- `snake_forward_45` 表示刚刚发送了蛇形直线 45 度命令
- `5/5` 表示五个体节全部发送成功

如果显示：

```text
last result: 3/5
```

说明只有 3 个体节当前有 TCP 连接并成功发送。

## 6. 建议测试顺序

第一次现场测试建议按下面顺序：

1. 启动程序，确认手柄显示 `connected`
2. 等待五个体节都连接，确认显示 `[0, 1, 2, 3, 4]`
3. 按 `Y`，让所有体节归位
4. 按 `A`，测试蛇形直线
5. 按 `X`，测试蛇形左转
6. 按 `B`，测试蛇形右转
7. 按十字键上，测试蠕虫步态 1
8. 按 `Y`，停止并归位

如果左右转方向和预期相反，优先检查 `STM32` 是否已经烧录最新版固件。

## 7. 常见问题

### 7.1 手柄显示未连接

先运行诊断脚本：

```powershell
python E:\Fudan\worms\codes\xbox_controller_diag.py
```

正常情况下应该能看到：

```text
slot=0 ret=0
```

如果所有槽位都是：

```text
ret=1167
```

说明 Windows 当前没有检测到手柄。

处理顺序：

1. 重新唤醒手柄
2. 重新插拔接收器或 USB 线
3. 确认手柄处于 Xbox/XInput 模式
4. 确认 Windows 能看到 `XINPUT compatible HID device`

### 7.2 手柄连接正常，但机器人不动

检查顺序：

1. 状态窗口里五个体节是否都连接
2. `last result` 是否为 `5/5`
3. 舵机电源是否上电
4. `STM32` 是否烧录了最新版
5. `ESP32` 的端口和体节号是否匹配

### 7.3 只有部分体节动

通常是部分 `ESP32` 没连上上位机。

检查：

- 对应体节是否上电
- 对应 `ESP32` 是否连上 Wi-Fi
- 对应 `ESP32` 端口是否正确
- 上位机窗口里该体节是否显示 connected

### 7.4 左右转方向不对

当前约定：

- `X` 是左转
- `B` 是右转

如果方向反了，优先确认 `STM32` 是否烧录了修正后的版本。

修正后的固件中：

- `0x04` 表示左转
- `0x05` 表示右转

### 7.5 转弯太急或太缓

当前转弯强度由 `STM32` 中的：

```c
#define SNAKE_TURN_BIAS_SPAN_DEG 15.0f
```

控制。

含义：

- 数值越大，转弯越急，半径越小
- 数值越小，转弯越缓，半径越大

当前 `15.0f` 属于较缓转向。
